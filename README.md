# E-Myth: разбор, система, применение

Рабочая среда для глубокого чтения книги Майкла Гербера «The E-Myth Revisited».
Не перевод книги — **разбор**: смысл, бизнес-модель, применение к своему делу.

---

## Как мы работаем

1. Ты читаешь главу сам — в оригинале или в официальном переводе.
2. Даёшь команду: **«Разбери главу N»**.
3. Появляется файл `analysis/chapter-NN.md` + PDF для чтения, всё уходит в git.
4. Попутно обновляются `glossary.md`, `key-concepts.md`, `progress.md`.

По одной главе за раз, по твоей команде. Порядок — как в книге.

## Что где лежит

| Путь | Что это |
|---|---|
| `analysis/chapter-NN.md` | **Основное.** Разбор главы по формату из 9 блоков |
| `analysis/pdf/` | Те же разборы в PDF — для чтения с телефона и планшета |
| `analysis/_template.md` | Шаблон формата разбора |
| `glossary.md` | Единый глоссарий терминов EN→RU (размечен по главам, есть спойлеры) |
| `key-concepts.md` | Карта концепций, накапливается по мере чтения |
| `business-model.md` | Итоговая схема системы Гербера, собирается из глав 10–18 |
| `progress.md` | Где мы находимся, что дальше |
| `workbook/` | Практические задания |
| `original/` | Оригинал книги (в git не попадает) |
| `CLAUDE.md` | Инструкция для Claude Code: как переводить, как разбирать |
| `tools/extract.py` | Достаёт текст главы из EPUB для работы |
| `tools/md2pdf.py` | Собирает PDF разбора из markdown |

## Формат разбора главы

Каждая глава разбирается по одним и тем же 9 блокам:

1. Перевод / адаптация
2. Главная идея
3. Что автор реально пытается сказать
4. Бизнес-принцип
5. Пример из книги
6. Как это выглядит в реальном бизнесе
7. Как это применить к моему будущему бизнесу
8. Какие вопросы я должен себе задать
9. Термины

## Про авторские права

Книга защищена авторским правом, поэтому в проекте **нет** её полного перевода
и файл оригинала не коммитится. Есть разбор, короткие цитаты с комментарием,
глоссарий и практика — то есть ровно то, чего в самой книге и в её переводе нет.

Если нужен русский текст книги — есть официальный перевод
(«Малый бизнес: от иллюзий к успеху»), его стоит купить.

## Статус

Оригинал на месте, разборы сверяются с текстом.
Готова **глава 1**. Дальше — по команде.

> «Разбери главу 2 по стандартному формату»
