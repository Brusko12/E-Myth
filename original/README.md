# Оригинал книги

Здесь лежит `e-myth.epub` — The E-Myth Revisited, Michael E. Gerber, HarperCollins
(ISBN 9780061741654). Издание с отдельными файлами глав: `chapter01`–`chapter19`,
плюс foreword, introduction, epilogue, afterword.

**Файл не коммитится в git** (см. `.gitignore`) — это защищённая авторским правом
книга, ей не место в публичном репозитории. Он живёт только локально.

## Как достать текст главы

```bash
python3 tools/extract.py 1        # глава 1
python3 tools/extract.py --list   # что вообще есть в книге
```

Текст падает в `.work/` — папка тоже не коммитится.
Полного текста книги в репозитории нет ни в каком виде.

## Если нужен русский текст книги

Ценность этого проекта в другом: в разборе, системе и применении, которых в переводе нет.
