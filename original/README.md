# Оригинал книги

Положи сюда файл книги: `e-myth.epub`, `.pdf` или `.txt`.

**Файл намеренно не коммитится в git** (см. `.gitignore` в корне) — это защищённая
авторским правом книга, ей не место в публичном репозитории. Он живёт только локально.

Пока файла нет, разборы пишутся по знанию текста, без опоры на конкретное издание.
Как только файл появится — скажи, и разборы будут привязаны к реальному тексту
с точными цитатами и ссылками на страницы.

Официальный русский перевод издан («Малый бизнес: от иллюзий к успеху») — если нужен
именно текст книги по-русски, его правильнее купить. Ценность этого проекта в другом:
в разборе, системе и применении, которых в переводе нет.
